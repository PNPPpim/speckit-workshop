# speckit-workshop

Photo Album Organizer application built with Speckit.

## Overview
A web application that helps organize photos into albums grouped by date, with drag-and-drop reorganization and tile-based photo preview interface.

## Features
- Albums grouped by date
- Drag-and-drop album reordering
- Tile-based photo preview
- No nested albums

## Installation

```bash
uvx --from git+https://github.com/github/spec-kit.git specify init --here
```

## Development

```bash
npm install
npm start
```
